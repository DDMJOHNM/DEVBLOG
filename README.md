## HydePHP

Elegant and powerful static site generator.

Docs: [hydephp.com/docs/2.x](https://hydephp.com/docs/2.x/)

### Useful commands

```bash
composer create-project hyde/hyde
php hyde publish:homepage
php hyde make:page
php hyde make:post
php hyde build
php hyde serve
```
