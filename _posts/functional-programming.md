## What “functional programming exposure” means

It means you understand and have used functional concepts that improve code quality, predictability, and testability — especially in JavaScript/TypeScript and React.

### 1. Pure functions

Functions that always return the same output for the same input and have no side effects.

**Used in:** reducers, selectors, utility functions.

### 2. Immutability

Data isn’t modified directly — instead you create new copies.

**Used in:** React state updates, Redux, spread operators, `Object.freeze`.

### 3. Higher-order functions

Functions that take functions as arguments or return functions.

**Used in:** `map`, `filter`, `reduce`, middleware, hooks.

### 4. Function composition

Building complex logic by combining small, reusable functions.

**Used in:** pipelines, utility libraries, Redux enhancers.

### 5. Declarative programming

Describing what you want, not how to do it.

**Used in:** React components, JSX, CSS, SQL.

### 6. Pure data transformations

Working with arrays, objects, and streams using predictable transformations.

**Used in:** API response shaping, ETL logic, analytics pipelines.

### 7. Recursion

Functions that call themselves to solve problems.

**Used in:** tree traversal, nested UI rendering, JSON parsing.
